# WowSkillsLand 前端原型

React、TypeScript 和 Vite 构建的校园 Skill 社区多页面交互原型。

## 运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

访问 `http://127.0.0.1:4173/`。

## 页面

- `/`：任务匹配首页
- `/explore`：探索技能与校园经验
- `/creator`：创作者主页、成长时间线、资产和赛博人格
- `/trust`：可信评测
- `/u/:handle`：公开个人主页

详细交接信息见 `HANDOFF.md`。
